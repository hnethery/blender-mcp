# Palette's Journal

## 2025-05-18 - [Blender Panel Organization]
**Learning:** Grouping Blender addon properties in UI boxes using `layout.box()` drastically improves readability compared to a flat list. Adding icons to operators clarifies their function.
**Action:** Always use `layout.box()` for distinct feature sets in Blender panels and look for appropriate built-in icons.

## 2025-05-19 - [Blender External Links]
**Learning:** Providing direct "Get API Key" links using `wm.url_open` next to API key inputs significantly reduces friction for users setting up integrations.
**Action:** Always verify if a setup step requires external action (like getting a key) and provide a deep link to that specific page if possible.
